# Підґрунтя пакетів Vortex

Блок підготовлений до майбутнього погодженого наповнення. Зараз він **не публікується**: у всіх п’яти мовах `homepage.vortex_pricing_section.visible` має значення `false`, а `plans` — порожній масив. Назви пакетів, суми й обіцянки щодо складу послуг не вигадані.

## Структура даних

`homepage.vortex_pricing_section`:

| Поле | Тип | Призначення |
| --- | --- | --- |
| `visible` | boolean | Явний дозвіл показати погоджені пакети. |
| `section_title` | string | Перекладений заголовок секції. |
| `section_description` | string | Перекладений вступ; можна лишити порожнім. |
| `plans` | array | Довільна кількість погоджених пакетів. |

Кожен запис `plans`:

| Поле | Тип | Призначення |
| --- | --- | --- |
| `id` | string | Стабільний ідентифікатор пакета. |
| `name` | string | Погоджена назва. |
| `description` | string | Опис, якщо потрібний. |
| `price` | number або null | Повна ціна пакета. `null` приховує суму; значення не підміняється нулем. |
| `currency` | string | Валюта ціни, отримана разом із пакетом. |
| `billing_period` | `monthly`, `yearly`, `one_time` | Період оплати. |
| `features` | string[] | Погоджений склад пакета. |
| `cta_text` | string | Текст кнопки. |
| `cta_target` | string | Внутрішній маршрут, якір, HTTPS, mailto, tel або `form:trial` / `form:demo`. |
| `highlighted` | boolean, необов’язково | Виділяє картку кольором рамки без додаткових рекламних позначок. |

Для активації треба внести погоджені дані та переклади у всі п’ять мов, перевірити посилання й лише потім увімкнути `visible`. Компонент також повертає `null`, якщо пакетів немає; видимі порожні картки або заглушки не створюються.

## Підключення

- `VortexPlansComponent` уже розміщений на головній перед чинним калькулятором. Його якір — `#vortex-plans`; `#pricing` залишається у калькулятора.
- `vortex-plans.css` містить адаптивне оформлення довільної кількості карток.
- `onPlanSelect(planId)` — необов’язкова точка підключення майбутнього сценарію вибору. Зараз передавання нового пакета до заявки не ввімкнене: тип і серверну перевірку заявки потрібно погодити окремо.
- `form:trial` і `form:demo` наразі ведуть до наявної форми `#trial-request`. Окремого режиму демонстрації цей блок не створює.
- Ціна `null` означає відсутність опублікованої суми; користувач бачить лише погоджений контент картки та її кнопку.
- Формула чинного калькулятора, його налаштування, тарифи розробки сайтів і ціни TecDoc не змінені.

Під час інтеграції CMS цю необов’язкову структуру варто включити до контракту контенту. Публікувати блок слід після дозволу відповідальної особи та погодження цін, умов і складу кожного пакета.
