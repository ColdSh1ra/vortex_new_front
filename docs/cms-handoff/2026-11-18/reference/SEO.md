# Технічне SEO Vortex

Реалізовано 17 листопада 2026 року. Зміни стосуються коду проєкту; публікація на продакшн і надсилання карти сайту до Search Console не виконувалися.

## Пошукове SEO

- Унікальні перекладені `title` і `description` для головної, контактів, FAQ, СТО, розробки сайтів, авторозбірки, ліцензії TecDoc, політики конфіденційності та семи інтеграцій. Для опублікованих статей метадані надходять із блогу API.
- Мова задається адресою: українська `/contact`, англійська `/contact?lang=en`, польська `?lang=pl`, чеська `?lang=cz`, словацька `?lang=sk`. Відповідні коди `hreflang`: `uk`, `en`, `pl`, `cs`, `sk`.
- Однаковий URL завжди віддає одну мову незалежно від cookie. `html lang`, `Content-Language`, контент, метадані, посилання й мікророзмітка узгоджені. Політика конфіденційності також перекладена повністю.
- Самопосилальний canonical, взаємні alternate/hreflang та `x-default` для індексованих сторінок. Мовний перемикач містить справжні HTML-посилання. Меню, футер, картки, breadcrumbs та CTA зберігають мову.
- 301-нормалізація кінцевого слеша, явного `lang=ua`, `page=1` і зайвих параметрів. Некоректна пагінація не перетворюється на головну блогу, а повертає 404. Фрагменти використовуються лише для навігації всередині сторінки.
- Open Graph і Twitter Cards із перекладеними текстами, мовою та коректними розмірами зображення. Для малого логотипа використовується картка `summary`, для достатньо великої обкладинки статті — `summary_large_image`.
- JSON-LD уже в серверному HTML: Organization, WebSite, WebPage / ContactPage / FAQPage / CollectionPage, SoftwareApplication, Service, BlogPosting для реальних статей і BreadcrumbList там, де є хлібні крихти. FAQ використовує видимі запитання й відповіді; дубльована стара розмітка прибрана.
- Справжні 404/503, `noindex` для помилок і демонстраційного блогу, `Retry-After` для тимчасової недоступності, `noindex` для API-відповідей.
- `/sitemap.xml` — індекс; `/sitemaps/pages.xml` — усі 75 мовних адрес основних сторінок із hreflang. Після підключення реального API додаються списки блогу та `/sitemaps/blog-N.xml` зі статтями, перекладами й справжніми датами оновлення. Демонстраційні статті не потрапляють у карту. Відмова API не прибирає основні сторінки з sitemap.
- `/robots.txt` дозволяє публічні сторінки й ресурси, закриває API та містить посилання на карту сайту.

## Завантаження та CSS

- Прибрано загальний preload 16 зображень постачальників/логотипів із шаблону. Сервер формує `preload` для потрібних CSS та першого важливого зображення конкретного маршруту, а `modulepreload` — із реального Vite manifest, без повторення вже згенерованих Vite-підказок.
- Підказки для зображень керуються в head; автоматичні React-підказки для всіх eager-картинок не перевантажують чергу preload. Відсутні локальні файли не додаються до preload.
- Критичні зображення мають пріоритет; великі зображення нижче першого екрана використовують lazy loading / asynchronous decoding. Для 52 локальних зображень зафіксовані природні розміри, щоб резервувати місце до завантаження.
- Google Fonts завантажує п’ять використаних накреслень замість 18; залишені preconnect і `display=swap`.
- Прибрано застарілі селектори та дубльовані перевизначення CSS. `main.css` разом із виділеним `pricing-calculator.css`: 74 780 → 60 521 байт, тобто −19,1%; на 737 рядків менше. Сторінка СТО більше не завантажує стилі всієї головної.
- Виробнича збірка мінімізує CSS, ділить JavaScript на кешовані частини. Сервер стискає HTML через Brotli/gzip, а файли з хешем мають `Cache-Control: immutable` на рік.

## Доступність для AI-пошуку

- Публічний контент і JSON-LD доступні без виконання JavaScript через SSR; ботам і людям віддається однаковий текст, без окремих прихованих версій.
- У robots явно дозволено OAI-SearchBot, Claude-SearchBot і PerplexityBot за тими самими правилами публічного доступу. Загальні правила доступу до навчальних роботів не змінювалися.
- `/llms.txt` містить опис продукту, канонічні посилання, мови та інтеграції. `/llms-full.txt` доповнює його описами можливостей, FAQ та публічними контактами. Обидва формуються з чинного контенту; `?lang=` перемикає мову. Ці допоміжні текстові файли позначені `noindex, follow`, щоб не конкурувати з HTML-сторінками.
- Узгоджені сутності Vortex / організація / програмний продукт / послуга, мовні URL і зрозумілі текстові блоки допомагають системам знаходити та співвідносити джерела.

`llms.txt` — додаткова навігаційна довідка, а не стандарт чи гарантія потрапляння в AI-відповіді. Google прямо вказує, що для AI-пошуку діють звичайні вимоги SEO, без спеціальної AI-мікророзмітки. Індексація та цитування залежать від зовнішніх пошукових систем.

## Перевірка й запуск

- `npm run build`: TypeScript, клієнтська збірка та SSR.
- Запущено 9 наявних серверних тестів. Нових тестових файлів не створено.
- HTTP-аудит усіх 75 мовних сторінок: метадані, canonical/hreflang, JSON-LD, мова HTML/заголовків/посилань, політика із 14 секціями, доступність preload-ресурсів, окремі стилі СТО, robots, sitemap, AI-довідки, 301/404, HEAD і Brotli.
- Тимчасова API-модель у пам’яті перевірила 15 мовних сторінок блогу, BlogPosting / CollectionPage, пагінацію, 85 адрес у карті сторінок і 100 адрес у карті статей, а також поведінку під час 404/503 і відмови API. Це перевірка інтеграції, не твердження про кількість реальних статей.
- Коміт не створено.

На продакшн слід запускати SSR-сервер (`npm run start:ssr`) або зібрати `npm run build` і запустити `npm run server:start`. Просте розміщення `dist/client` як статичного SPA не відтворює серверні метадані, мовні відповіді, sitemap і AI-довідки. Домен у `shared/site.json` має відповідати фактичному HTTPS-домену. Для реального блогу потрібен `BLOG_API_BASE_URL`; після публікації карту сайту можна додати до Google Search Console та Bing Webmaster Tools.

## Підтримка

- `shared/site.json`: домен, мови й список статичних маршрутів для sitemap.
- `client/src/seo/copy.ts`: перекладені метадані; `metadata.ts`: метадані й JSON-LD; `urls.ts`: мовні адреси.
- `server/src/seo/resources.js`: відповідність маршруту критичним CSS і зображенню.
- `client/src/data/imageDimensions.json`: актуалізувати розміри після заміни зображень.
- Додаючи сторінку, додайте її реальний контент і маршрут, SEO-переклади, запис у перелік сторінок та потрібний CSS / критичне зображення.

Джерела вимог: [мовні версії Google](https://developers.google.com/search/docs/specialty/international/localized-versions), [AI-функції Google](https://developers.google.com/search/docs/appearance/ai-features), [роботи OpenAI](https://developers.openai.com/api/docs/bots), [роботи Perplexity](https://docs.perplexity.ai/docs/resources/perplexity-crawlers), [preload](https://web.dev/articles/preload-critical-assets).
